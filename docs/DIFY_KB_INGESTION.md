# Dify KB Ingestion

## Inputs

- Source JSON: `crystal_knowledge_base_final-90b679ba5d.json`
- Prepared markdown corpus: `dify_kb_docs/`

The markdown corpus is generated by:

```bash
python3 scripts/prepare_dify_kb.py \
  --input crystal_knowledge_base_final-90b679ba5d.json \
  --output dify_kb_docs
```

## Ingestion script

Primary script:

- `scripts/ingest_kb_to_dify.py`

Wrapper (bootstrap + ingestion):

- `scripts/run_kb_ingestion.sh`

## What `ingest_kb_to_dify.py` does

1. waits for `/console/api/setup`,
2. logs in to Dify console with cookie + CSRF flow,
3. finds or creates dataset by name,
4. uploads each markdown file through `/console/api/files/upload`,
5. creates dataset documents via `/console/api/datasets/{id}/documents`.

Default indexing mode is `economy` to avoid requiring embedding-provider setup during local bring-up.

## Default command

```bash
python3 scripts/ingest_kb_to_dify.py \
  --base-url http://localhost:18080 \
  --email askcrystal.admin@example.com \
  --password Askcrystal123 \
  --dataset-name AskCrystal-KB \
  --kb-dir /Users/haokaiqin/Desktop/AskCrystal/dify_kb_docs \
  --indexing-technique economy \
  --skip-existing
```

## Idempotency behavior

- Dataset is reused when `--dataset-name` already exists.
- With `--skip-existing` (default), docs are skipped by existing document filename.
