## 1. 项目概述

### 1.1 我们要做什么

> *"你的专属 AI 水晶向导，为你匹配当下能量最契合的那颗水晶。"*

AskCrystal 是一个 **AI-First 的灵性健康电商平台**。它通过对话式 AI 诊断用户的情绪与能量状态，并在沉浸式聊天体验中，推荐高度匹配的水晶首饰，实现“精聊即转化”的购物闭环。

### 1.2 核心价值主张

| 传统水晶电商 | AskCrystal |
|---|---|
| 海量商品列表，用户自己翻找 | 告诉 AI 你的感受，AI 为你精准匹配 |
| 静态、冰冷的商品描述 | 个性化的“能量处方”与心理共鸣 |
| 转化率低（2-4%） | 通过信任建立与情绪陪伴，大幅提升转化 |
| 一次性交易 | 持续的“能量陪伴”与复购关系 |

### 1.3 商业模式

- **核心收入：** 水晶首饰及配饰直销（客单价 $29–$149）
- **次要收入：** 高级 AI 深度解析报告、显化工具包（Manifestation Kits）、每周能量预报订阅
- **毛利目标：** 70%+（直采供应链 + AI 驱动的连带销售）

## 4. 用户体验设计 (UX)

### 4.1 落地页 (Agent First)

**URL：** `/` (首页)

**布局：**
- 全屏沉浸式聊天界面（无传统轮播图/Banner）
- AI 主动发起欢迎对话，引导用户开口
- **4 个快速启动按钮**（降低输入门槛）：
  - "💔 感到焦虑/受阻" (Feeling anxious/stuck)
  - "💰 想吸引财富/丰盛" (Looking for abundance)
  - "🌸 需要感情/人际关系指引" (Need help with love/relationships)
  - "🔮 纯好奇 — 测测我的能量" (Just curious about my path)
- 右上角导航：保留 **"Shop All"** 按钮（跳转至标准商品列表页，服务不想聊天的用户）
- 底部信任标识：*"Powered by AI Energy Matching | 12,000+ Crystals Matched"*

### 4.2 对话流程 (Conversation Flow)

1. **破冰与建档 (2-3 轮)：**
   - AI 引导输入出生日期（可选，用于八字/星盘）+ 当前情绪状态
   - 生成个人“能量蓝图”摘要，建立权威感
2. **深度诊断 (3-5 轮)：**
   - AI 结合心理学话术与玄学框架，深挖用户痛点
   - 通过“冷读+共情”建立极高信任
3. **推荐与转化 (Conversion Point)：**
   - AI 以“能量处方”形式推荐 1-3 款水晶
   - **对话气泡内直接渲染商品卡片**：
     - 包含：高清图、名称、价格、"加入购物车"按钮
     - 个性化理由：*"这款紫水晶手链正对应你当下需要的‘静心’能量。"*
4. **购后陪伴 (Retention)：**
   - AI 发送消磁/启用指南
   - 引导订阅“每周能量预报”，为复购铺路

### 4.3 商品详情页 (SEO)

- 标准 Shopify 商品页，用于承接 Google 搜索流量
- 富含 SEO 优化的长描述、用户评价、结构化数据 (Schema Markup)

### 4.4 列表/分类页 (SEO)

- 分类维度：意图（财富/爱情/平静）、五行元素、水晶种类
- 完全可被 Google 爬虫收录，保留 Shopify 原生 SEO 优势

## 6. AI Agent 设计 (Dify)

### 6.1 System Prompt 架构

- **角色设定：** “你是 Numen，一位 AI 能量向导与水晶策展人。你融合东方玄学智慧（八字、五行）与西方灵性心理学（脉轮、显化法则），帮助用户找到当下最契合的水晶。”
- **语气风格：** 共情、睿智、现代、不说教、不搞封建迷信
- **安全边界 (Guardrails)：**
  - 绝不做出医疗/健康承诺
  - 附带“仅供娱乐/身心疗愈参考”免责声明
  - 所有推荐必须通过 Tool 调用真实商品库，禁止凭空捏造

### 6.2 工具定义 (Dify Tools)

| 工具名 | 功能 | 对接 API |
|---|---|---|
| `search_crystals` | 按标签/意图查询 Shopify 商品 | Shopify Storefront API (GraphQL) |
| `get_product_details` | 获取完整商品详情用于卡片渲染 | Shopify Storefront API |
| `generate_energy_report` | (后期) 生成 PDF 能量报告 | 自定义接口 |

### 6.3 知识库 (RAG)

- 《水晶属性大全》（500+ 条目：名称、物理/灵性属性、频率、疗愈用途）
- 《五行与八字基础解读指南》
- 《七大脉轮系统参考》
- 《心理-水晶映射表》（如：焦虑→紫水晶/锂辉石）

## 9. 风险与应对

| 风险 | 影响等级 | 应对策略 |
|---|---|---|
| **广告平台政策封杀** (Meta/Google 对玄学限制) | 高 | 包装为“身心健康/自我探索”，避开“算命/占卜”敏感词 |
| **AI 幻觉 (推荐错误商品)** | 中 | 强制 RAG 检索 + Tool 调用真实库存，禁止 AI 自由发挥商品名 |
| **用户对 AI 推荐信任度低** | 中 | 展示真实水晶参数、客户评价、透明溯源 |
| **支付网关风控** (Stripe/PayPal 拦截玄学交易) | 低 | 账单描述使用“Wellness Products”或“Jewelry” |
| **Shopify API 频率限制** | 低 | 商品搜索结果做本地缓存，减少重复调用 |
